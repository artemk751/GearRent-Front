# GearRent — Frontend

Фронтенд платформи оренди спорядження GearRent: каталог товарів та авторизація (реєстрація, вхід, вихід, захищені сторінки). Чистий HTML, CSS і JavaScript, без збирання та залежностей. Працює з бекендом [GearRent](https://github.com/artemk751/GearRent).

## Функціонал

| Сторінка | Адреса | Хто бачить |
|---|---|---|
| Каталог (пошук, фільтри за категорією та брендом, сортування) | `#/` | усі |
| Реєстрація | `#/register` | лише неавторизовані |
| Вхід | `#/login` | лише неавторизовані |
| Профіль | `#/profile` | лише авторизовані |
| Додавання товару | `#/products/new` | лише авторизовані |
| Список користувачів | `#/users` | лише адміністратори |

Додатково в каталозі адміністратор бачить кнопку «Видалити» біля товарів.


## Структура

```
templates/index.html  — сторінка (SPA з hash-маршрутами)
templates/app.js      — маршрутизація, запити до API, токени
static/styles.css     — стилі
```

## Запуск

1. Запустіть бекенд:
   ```bash
   python manage.py migrate
   python manage.py loaddata demo_data
   python manage.py createsuperuser
   python manage.py runserver
   ```
2. У корені цього репозиторію запустіть простий веб-сервер на порту 5500:
   ```bash
   python -m http.server 5500
   ```
3. Відкрийте **http://localhost:5500/templates/index.html**

Не відкривайте `index.html` подвійним кліком (`file://`): браузер блокуватиме запити до API.

## Як перевірити

1. Відкрийте `http://localhost:5500/templates/index.html#/profile` без входу: вас перенаправить на вхід. Після входу ви повернетесь на профіль.
2. Зареєструйтеся (`#/register`) і увійдіть. У шапці з'явиться ваше ім'я та кнопка «Вийти».
3. Спробуйте відкрити `#/login` після входу: вас перекине на профіль.
4. Увійдіть під адміністратором (створений через `createsuperuser`): з'являться «Користувачі» та кнопка «Видалити» в каталозі. Звичайний користувач на `#/users` побачить повідомлення про відсутність прав.
5. Перевірка автооновлення токена: тимчасово встановіть `ACCESS_TOKEN_LIFETIME` у `SIMPLE_JWT` (бекенд, `config/settings.py`) 15–20 секунд, увійдіть, зачекайте й оновіть профіль. У вкладці Network буде видно запит `401`, потім `auth/refresh`, потім повторний успішний запит.
